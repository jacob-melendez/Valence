# Self-hosted fonts

Served from the site itself so the page makes no third-party requests (the CSP allows fonts from `'self'` only).

| File | Font | Source | License |
|---|---|---|---|
| `space-grotesk-latin.woff2` | Space Grotesk (variable, latin subset) | Google Fonts, `fonts.gstatic.com/s/spacegrotesk/v22` | SIL Open Font License 1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono (variable, latin subset) | Google Fonts, `fonts.gstatic.com/s/jetbrainsmono/v24` | SIL Open Font License 1.1 |

The OFL allows bundling and redistribution with software; the fonts are not modified.
